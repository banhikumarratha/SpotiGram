# User Stories

## Epic 1: New User Journey
- **US1.1**: As a new user, I want to sign up using my Email and Password or Spotify OAuth so that I have flexible login options.
- **US1.2**: As a new user, I want to connect my Spotify account and be informed that Spotify Premium is required for playback.
- **US1.3**: As a new user, I want my Spotify tokens to auto-refresh in the background so my session isn't interrupted.
- **US1.4**: As a new user, I want to see my initial "Music DNA" generated based on my listening history.
- **US1.5**: As a new user, I want to use the Mood Scanner via my webcam to get immediate music recommendations.

## Epic 2: Returning User Journey
- **US2.1**: As a returning user, I want to log in and immediately see my personalized, balanced Feed.
- **US2.2**: As a returning user, I want to interact with the AI DJ powered by the default local Ollama model to request a specific vibe without incurring cloud costs.
- **US2.3**: As a returning user, I want to seamlessly control Spotify playback within the Streamlit UI, powered by background JavaScript.
- **US2.4**: As a returning user, I want to Mute or Block disruptive users, or Report inappropriate comments to maintain a healthy feed.
- **US2.5**: As a returning user, I want to leave Voice Reactions on my friends' shared tracks.

## Epic 3: Power User Journey
- **US3.1**: As a power user, I want to switch my AI DJ provider to Gemini or Grok in the settings for more advanced conversational capabilities.
- **US3.2**: As a power user, I want to curate and publish collaborative playlists directly from Spotigram.
- **US3.3**: As a power user, I want to view my advanced Analytics dashboard to see how my taste is evolving.
- **US3.4**: As a power user, I want to discover obscure metadata about tracks, knowing the system falls back to MusicBrainz/Last.fm if Spotify lacks details.
